# Checkpoint 6 — Scratch Exercise

Scratch models the same computation as text-based imperative programming:
- **Initialization & State:** `set x to 5` initializes memory (x = 5).
- **Mutation:** `change x by 3` mutates state (x ← x + 3), resulting in 8.
- **Sequential Flow:** Blocks execute top-to-bottom in order, identical to code execution line-by-line.
- **Output:** The `say` block serves as an abstraction for standard output (`print()`).

Though visual blocks prevent syntax errors, the underlying control flow and memory mutation mechanics remain identical.
